The `esp_audio_stack` speaker platform writes playback audio into the
full-duplex audio backend owned by the `esp_audio_stack` component. The stack
writes at its parent bus rate; upstream ESPHome resampler/mixer speakers convert
sources at other rates. The stack owns buffering, codec output and the
echo-cancellation reference.

The accepted stream is signed 16-bit PCM at the parent bus rate and playback
channel count. Format declarations must match the parent and do not add a
converter. Use the native resampler for sources at another rate.

```yaml
esp_audio_stack:
  id: audio_stack
  sample_rate: 48000

speaker:
  - platform: esp_audio_stack
    id: stack_speaker
    esp_audio_stack_id: audio_stack
    buffer_duration: 500ms
```

## Configuration variables

- **esp_audio_stack_id** (*Optional*, ID): The parent `esp_audio_stack` component; inferred when exactly one is available.
- **id** (*Optional*, ID): Manually specify the speaker ID.
- **buffer_duration** (*Optional*, time): Playback staging buffer size, default 500 ms.
- **timeout** (*Optional*, time): Auto-stop after the queue drains and no new PCM is written for this interval. Defaults to no automatic timeout.
